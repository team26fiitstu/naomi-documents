# NAOMI Methodologies

LaTeX sources for the NAOMI team's NAO Robot Exercise System methodologies. Both documents use the team's NAOMI LaTeX template.

The technical methodology covers coding conventions, code review, and verification. The version control methodology covers branches, commits, pull requests, and releases.
